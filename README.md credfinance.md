# CredMoney Finance – Field Recovery Performance Dashboard (April 2026)



## Overview

This project is an interactive Microsoft Excel dashboard built for a fictional fintech company, CredMoney Finance.  
The dashboard was designed to track and visualize the performance of field recovery teams across different states and supervisors.

The focus of the dashboard is not just reporting numbers, but telling a performance story through clean visuals, KPIs, and insights.



## Dashboard Objectives

The dashboard helps management to:

* Monitor recovery performance against targets
* Identify top-performing and underperforming states
* Track roll rate trends
* Evaluate supervisor/team lead effectiveness
* Support faster recovery strategy decisions



## Key Metrics Tracked

### Recovery Performance

* Total Target Amount
* Total Cash Recoveries
* % Target Achievement

### Roll Rate Performance

* Roll Rate %
* Roll Rate Dip
* High-Risk Recovery Segments

### Team Performance

* Team Lead Recovery Contributions (90% benchmark tracking)
* Best Performing Teams
* Teams Needing Support

### Geographic Performance

* State-Level Recovery Performance
* Top Performing States
